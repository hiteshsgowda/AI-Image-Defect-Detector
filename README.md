​AI Image Defect Detector
​A Deep Learning computer vision system built using Python and TensorFlow/Keras. The project utilizes a Convolutional Neural Network (CNN) to automatically scan imagery and classify industrial components as either "Normal" or "Defective" based on surface anomalies.
​Tech Stack & Concepts Used
​Language: Python
​Deep Learning Framework: TensorFlow / Keras
​Architecture: Convolutional Neural Networks (Conv2D, MaxPooling2D, Flatten, Dense)
​Concepts: Computer Vision, Data Tuning, Binary Classification Optimization
​Results
​Optimized the neural network layer constraints and data exposure across 10 training epochs, successfully moving the model tracking accuracy from a baseline evaluation up to a definitive 100.0% classification success rate on unseen validation datasets.
